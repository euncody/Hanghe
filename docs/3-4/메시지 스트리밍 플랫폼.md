## 메시지 스트리밍 플랫폼이란?

* **메시지(Message)**: 시스템 간에 주고받는 데이터 단위 (예: 주문 이벤트, 로그 기록, 결제 완료 신호).
* **스트리밍(Streaming)**: 데이터를 한꺼번에 모아서 처리하는 게 아니라, **실시간으로 흘러가는 데이터 흐름을 계속 받아 처리**하는 방식.
* **플랫폼(Platform)**: 이러한 메시지를 안전하게 전달·저장·처리할 수 있도록 도와주는 기반 시스템.

즉, \*\*메시지 스트리밍 플랫폼 = “실시간으로 발생하는 데이터를 안전하게 받아서 다른 시스템에 전달해주는 기반 시스템”\*\*이에요.

---

## 쉽게 예를 들면

* **메시지 큐(MQ)**: 우체통 같은 역할 → 편지를(데이터를) 넣어두면 나중에 가져가는 방식.
* **메시지 스트리밍 플랫폼(카프카)**: 편지가 끊임없이 흘러가는 **컨베이어 벨트**처럼, 도착 즉시 여러 사람이 동시에 꺼내서 처리할 수 있는 시스템.

---

👉 그래서 **Kafka**는 단순 메시지 큐(MQ)가 아니라, **실시간 스트리밍 데이터 파이프라인과 이벤트 처리 플랫폼**이라고 불립니다.
